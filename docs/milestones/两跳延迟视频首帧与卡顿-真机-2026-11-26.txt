四、关键结论
────────────
1. **稳态无卡顿、零丢帧**：路程 RTT 升至 400 ms 时，1920x1080@30fps 仍保持 27.7~27.9 fps、
   `drop=0 / steady_drop=0`、画质相关系数 `0.9999`（无花屏）。
2. **视频通道内首帧（`first_ms`）不随 RTT 恶化**：全档位稳定在 185~230 ms。
3. **用户体感首帧（`e2e_first_ms`）线性受制于建会话 ≈5 RTT**：
   0 ms 档 467~531 ms → 100 ms 档 890~891 ms → 200 ms 档 1437~1641 ms → 400 ms 档 2452 ms
   （斜率 ≈ 4.9 RTT，与 11-23 测得的固定握手开销口径一致）。
4. **降码率救不了高延迟首帧**：`d50-fast` 码率从 7747 降到 1243 kbps（−84%），`e2e_first_ms`
   仍为 1484~1641 ms，与 `d50-auto`（1437~1641 ms）同档。要缩短广域网首帧，必须压缩握手往返数。
