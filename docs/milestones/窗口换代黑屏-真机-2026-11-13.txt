窗口换代黑屏 · 真机实测（2026-11-13 夜批 05:00 班）
====================================================

命题（M2.5 分辨率跟随遗留的最后一格）
------------------------------------
被控端换分辨率 → 控制端重建解码器的**那一刻**，窗口会不会「黑屏一拍」？
以前算未验：帧计数（painted）看不出一次 33 ms 的全黑。本轮把它变成机器可查。

方法（两条独立判据 + 一条时间线）
--------------------------------
1. Windows 侧 `tools/win_window_capture.py`：`PrintWindow`（**只用 PW_CLIENTONLY** ——
   带 PW_RENDERFULLCONTENT 每次 280~770 ms，实测对照，判据会被它拖死）抓客户区位图，
   64x64 网格采样，20 ms 名义间隔（实测中位 12 ms，34 秒 1700 帧）。
2. 真机 `xrandr --fb 800x600`（800x600 比窗口 1280x720 小 → fit_rect 从不缩小 →
   黑边占比必须从 ~0 跳到 ~0.47 —— **这个跳变本身就是「抓取通路是活的、窗口确实在跟
   远端画幅走」的自证**，比「看到画面」更硬）；再 `--fb 1920x1080` 换回去，黑边回落。
3. `tools/analyze_window_blackframe.py` 找「黑闪 run」：连续采样点 black_frac ≥ max(0.90,
   基线+0.25)、前后邻点都低 0.25 以上、且严格位于文件内部。20 ms 采样对 33 ms 的一拍黑
   是必中的（33 ≥ 20）。
   **两类全黑签名必须分开**（这是本轮判读器定下来的口径）：
    - 控制端空白（要判的缺陷）：统一 0x101010 铺满 —— 首帧前占位、或 blit 清屏后帧被
      跳过提前 return。签名 mean≈16（阈值 ≥13）。
    - 对面真黑（正确行为）：host 发来的全黑视频帧 —— 黑边(16)+黑视频(0) 混合，
      mean = 黑边占比×16。签名 <13。

代码层的机理（先读后验）
------------------------
换代期间不存在能让窗口呈现空表面的路径：`latest` 帧走 tokio watch 通道、只发
`Some(frame)`，从不发 `None`；`redraw` 对「同一帧」提前 return（位图原样保留残影）；
`blit` 清屏与铺帧在同一次调用里完成后才 present —— 清屏态永远不会单独见屏。

结果（真机 mis-pc，/opt/uulan 现网服务，未动任何服务；两轮）
--------------------------------------------------------------
Run 1（bf-20261113_051710）：1700 采样 / 黑边 0.001 -> 0.4716 -> 0.001 /
  **控制端空白 run = 0**；host 真黑 run = 1，恰在 restore+376 ms、单采样点、
  mean=7.54 = 0.4716×16 —— 数学上只可能是「视频区全黑 + 黑边」，即 X 桌面
  在 `--fb` 改回 1920 的重绘瞬间自己黑了一帧、被窗口如实画出来。不是控制端黑屏。
Run 2（bf-20261113_051929）：1700 采样 / 同样三段黑边 / **空白 0、host 真黑也 0**
  —— 那个黑帧是偶发的 host 侧行为，判据没把它吞掉，也没把它算成控制端缺陷。
同轮控制端日志（Run 2）：收到 AU 1367 / 解出 1359 / 丢帧 0 / 首帧 204 ms /
  被控端 30 fps / 重建解码器 2 次 / 会话建立 1 条、断线接回 0 次 / painted=1491 /
  「窗口已就绪」恰好 1 次（窗口没重建）/ 退出码 0。
断言 16/16 通过（首轮判据未分签名时 15/16，那条 FAIL 就是上面 Run 1 的 host 真黑帧，
判据修正后按签名归类 —— 修正记录在 tools/analyze_window_blackframe.py 注释里）。

结论
----
「窗口在换代那一刻黑屏一拍」= **没有**：两轮共 3400 个毫秒级采样（20 ms 分辨率），
控制端空白全黑 0 次；换代期间窗口一直保持上一帧残影，直到新代第一帧到达。
唯一的整窗近黑是一次对面直播来的真黑帧（host 桌面换 xrandr 尺寸瞬间），属正确镜像。
遗留仍只有多显示器/副屏热插拔（这台真机 VGA/HDMI 都 disconnected，造不出第二条输出）。
