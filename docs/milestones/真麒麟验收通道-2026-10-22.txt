  ⚠ 只编 server + host。客户端在真机上编不了：winit/softbuffer 的 X11 后端要 x11.pc，
     而 libx11-dev 在麒麟源里装不上（源里 libx11-dev 依赖 libx11-6 = 2:1.6.9-2kylin1.2，
     系统装的是 2:1.6.9-2kylin1.6，dev 包落后于运行时包）。

【本次为让真机编得过所做的两处改动】
  1) crates/uulan-client/Cargo.toml：winit/softbuffer 的平台特性分开写。
     cfg(windows) 只需 rwh_06；cfg(unix) 必须显式开 x11（softbuffer 还要 features=["x11"]），
     否则它的 make_dispatch! 宏不生成任何分支 → E0004 非穷尽匹配，编译直接失败。
     这个错只有真机上才编得出来（本机 Windows 一路编得过）。
  2) 真机侧补了链接器 dev 软链（可用 `rm` 撤销）：
     /usr/lib/x86_64-linux-gnu/libX11.so  -> libX11.so.6
     /usr/lib/x86_64-linux-gnu/libXtst.so -> libXtst.so.6
     少了它编 host 会报 unable to find library -lX11 / -lXtst（XTest 注入需要）。
