四、这条为什么算「往应用里打字/拖拽」验过

  - 目标是一个**真实 X 应用窗口**（xev 在真机 :0 上，不是 Xvfb、不是离屏）；
  - 键盘经协议 → 被控端 Mapper → XTest → X 服务器 → 应用事件队列，应用自己打印出 5 个 KeyPress；
  - 拖拽链路完整：ButtonPress(1) → 3 次 MotionNotify → ButtonRelease(1)，即「按下-移动-松开」都在应用里发生；
  - 客户端「未送出 0 / 被控端拒绝 0」说明 17 条帧全部被接受，没有中途丢弃。

五、顺带说明的两点

  1. 真机分辨率现在是 **1024x768**（此前多为 1920x1080）。本项注入用的是绝对屏幕坐标，
     1024x768 下 (330,318) 落在 xev 窗口内，判据成立；分辨率跟随另有专项验收（见
     docs/milestones/分辨率跟随-真机-2026-11-01.txt）。
  2. 验收脚本 `scripts/verify-input-e2e.sh` 的三态退出码有用：本轮第一跑因协议不匹配返回 1（跑了但不达标），
     而不是把它误报成「未验」。
