一、这一格补的是什么
  DESIGN 一直写着「控制端同时支持麒麟和 Windows」，但面板（uulan-gui）在麒麟上只验到
  「窗口能起来、本机信息页排版正确」（11-20 / 11-21）。**控制端那一页（第一个标签页）
  从来没在麒麟上真正驱动过一条会话**，所以下面三件事都是空白：
    ① 面板拼出的 argv 在麒麟上跑真控制端，能不能出画面；
    ② 「开一个远端终端」在麒麟上是什么行为；
    ③ 会话收尾时面板的结论（退出码 / 用时）在麒麟上对不对。
  本轮把三格都做了，并且第 ② 格一验就是**真产品 bug**（见第三节）。

二·补、直连模式（不经中继）也从面板点通了
  同一构建，把表单的「直连地址」填 `192.168.223.15:21117`（中继地址留空）→ 子进程 argv 是
    `uulan-client --direct 192.168.223.15:21117 --password-file …/gui-current.pw`
  （**只发 --direct，没有 --server/--device**，与 `route_args` 的互斥纪律一致）→ 会话
  **收到 AU 438 / 关键帧 30 / 解出帧 437 / 丢帧 0 / 首帧 276 ms**，窗口标题
  `uulan · 麒麟真机(linux) · 1920x1080 · 画面 1280x720 · 30 fps · 7880 kbps · 首帧 276ms …`；
  关窗后 `远程会话已结束（正常收工，用时 14 秒）`。
  说明：直连这条路本身 11-19/11-20 已在命令行上验过（见「直连模式」一节），
  本轮补的是**从面板点下去**这一下（表单 → 互斥 argv → 真会话）。

三、「开一个远端终端」是个死按钮（真产品 bug，两端同族）
  症状：点一下，桌面什么都没发生。`gui-actions.log` 只有一行「执行：uulan-client … --term」，
  `gui-session.log` 里留下 `mis@mis-pc:~$ ` 就再没有下文。
  原因（终端模式和桌面模式走了同一条 spawn）：
    · stdout/stderr 被接进 `gui-session.log`（GUI 子系统没有控制台，桌面模式需要它排错）；
    · stdin 继承面板的 `/dev/null`（面板是 `setsid nohup … < /dev/null` 起的）；
    · Windows 上还套了 `CREATE_NO_WINDOW`。
  于是远端 shell 一拿到提示符，stdin 立刻 EOF → 控制端按「本机 stdin 结束」的既有纪律
  发 EOT 收尾 → 进程秒退。**用户侧只看到什么都没发生**，日志里那句提示符是唯一痕迹。
  修法（`crates/uulan-gui`，协议零变化）：
    · unix：按候选表在 PATH 里找终端模拟器
      （`x-terminal-emulator` / `ukui-terminal` / `mate-terminal` / `gnome-terminal` /
      `xfce4-terminal` / `konsole` / `lxterminal` / `xterm`），用
      `<终端> -e <控制端> <参数…>` 起它，输入输出都留在那个窗口里；
      一个都没有 → 红字写清「试过哪些」+ 可照抄的手工命令，不静默。
    · Windows：终端模式改用 `CREATE_NEW_CONSOLE`（桌面模式仍 `CREATE_NO_WINDOW`），
      并且**不再重定向**子进程输出 —— 没有控制台可打字的终端等于没有终端。
    · 收尾话术分家：终端模式下面板手里是**终端模拟器**的退出码，不是远端 shell 的
      （`term_end_note`）；不到 10 秒秒退时不再指向上一轮桌面会话的旧日志。
  真机复验（麒麟）：点按钮 →
    `mate-terminal -x /home/mis/.local/uulan/bin/uulan-client … --term`（`pgrep -a` 原样）
    → 终端窗口 652x440，标题 `mis@mis-pc: ~`；
    `xdotool type 'echo UULAN-GUI-TERM-OK; id -un; date'` +
    `xdotool key Return` → 窗口里出现
      `UULAN-GUI-TERM-OK`
      `mis`
      `2026年 11月 22日 星期日 01:14:47 CST`
    → `exit 5` 后窗口关闭，面板记
      `远端终端窗口已关闭（终端程序退出码 255，用时 33 秒）—— 远端 shell 自己的退出码在那个窗口里`。
    注意这个 255：mate-terminal 把子进程的非零退出压成 255，所以**面板拿到的退出码与
    远端 shell 的退出码无关** —— 这正是收尾措辞必须写清归属的原因。
